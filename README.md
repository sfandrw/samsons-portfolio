# Samson Portfolio

A simple static portfolio starter for GitHub Pages.

## Files

- `index.html` — page structure and content
- `style.css` — styling and responsive layout
- `script.js` — mobile navigation and footer year
- `assets/images/` — put portfolio images here
- `assets/icons/` — put icons here

## Preview locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload/push all files in this folder.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

After the temporary GitHub Pages URL works, connect the custom domain.
